# FinanceLite - Personal Finance Dashboard

Platform pencatatan keuangan modern berbasis web dengan arsitektur reaktif, kontainerisasi Docker, serta dukungan mode gelap & terang instan.

## Fitur Utama
- Halaman Landing / Beranda Modern
- Autentikasi Pengguna (Daftar & Masuk)
- Dashboard Ringkasan Saldo (Saldo Bersih, Total Pemasukan, Total Pengeluaran)
- Form Input Transaksi (Keterangan, Nominal, Tipe, Kategori)
- Riwayat Transaksi Interaktif (dengan fitur Hapus)
- Fitur Dark / Light Mode Toggle

## Panduan Menjalankan Proyek
```bash
npm install
npm run dev
